Implemente um sistema de menu de navegação baseado em árvore genérica. Cada nó representa uma opção de menu, e os filhos são submenus.

typedef struct NoMenu {
    int id;
    char titulo[50];
    struct NoMenu *primeiro_filho;
    struct NoMenu *proximo_irmao;
} NoMenu;
Implemente um programa que:

Constrói a árvore de menus a partir da entrada

Exibe o menu atual e permite ao usuário navegar

0 volta ao menu anterior (ou sai se estiver no menu raiz)

Um número positivo entra no submenu correspondente (se existir)

Uma letra S sai do programa

Entrada:

Primeira linha: N (número de nós)

Próximas N linhas: id_pai id_filho titulo (id_pai = -1 para a raiz)

Próximas linhas: comandos de navegação (números ou 'S')

Saída:

O menu atual é exibido antes de cada comando

Após cada comando, o novo menu é exibido
