Um sistema de controle de versões organiza os commits de um projeto em uma árvore genérica, onde cada commit pode ter vários commits filhos (ramificações). Cada commit possui um identificador e um número de alterações (linhas modificadas).

Implemente um sistema que processa os seguintes comandos:

COMMIT pai id alteracoes: criar um novo commit como filho de pai (pai = -1 para o commit inicial)

TOTAL id: imprimir o total de alterações no commit id e em todos os seus descendentes

PROFUNDIDADE id: imprimir a profundidade do commit id na árvore (raiz = 0)

CAMINHO id: imprimir o caminho da raiz até o commit id

LISTAR: imprimir todos os commits em BFS (nível por nível)

FIM: encerrar

Entrada:

Múltiplas linhas com comandos

A entrada termina com FIM

Os IDs são únicos e inteiros positivos

Saída:

Para TOTAL: o total de alterações na subárvore

Para PROFUNDIDADE: a profundidade do commit

Para CAMINHO: os IDs da raiz até o commit, separados por espaço

Para LISTAR: os IDs em BFS separados por espaço
