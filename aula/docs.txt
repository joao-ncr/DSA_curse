O primeiro tema prático tratado em aula se baseia em recursão >> uma função que, ao não encontrar seu caso base, retorna a si mesma

Anotomia mínima: 
Caso base: 
a condição que não chama a função = o "chão" -> sem ele, a função nunca para (stack overflow)

Caso recursivo: 
a parte que chama a função de novo, mas com um argumento mais próximo do caso base.

ex:
void contagem(int n) {
    if (n == 0)            // <- caso base: para aqui
        printf("Fogo!\n");
    else {
        contagem(n-1);      // <- caso recursivo: chama com n-1 (mais perto de 0)
        printf("%d...", n);
    }
}
uma nova chamada de função a cada passo, cada uma criando seu próprio frame na pilha, com sua própria cópia de n. 
Contagem(3) não "vira" contagem(2); ela chama contagem(2) e fica pausada esperando essa chamada terminar. 
São 4 execuções distintas empilhadas (n=3, n=2, n=1, n=0), não uma única execução andando por valores.
Por isso a exibição se da em 1...2...3...4

Próximo nível: quando uma função retorna um valor

float potencia(float base, int expoente) { // define os parâmetros base e expoente
    if (expoente == 0)
        return 1; // caso base
    else
        return base * potencia(base, expoente - 1);
}

(2,3) 
2^3 precisa do resultado de 2^2 (que é exatamente -> (base, expoente -1)) = base: 2 ; expoente: 3 - 1 = 2 =====> 4
4 * base = 8 = 2^3

(2,2)...
(2,1)...
(2,0) > caso base: expoente = 0 -> retorna 1. Fim da pilha
